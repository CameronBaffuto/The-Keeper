# The Keeper 🏠👻

Personal home knowledge system backed by Cloudflare Workers + AI Search.

## Structure
- /backend – Cloudflare Worker (API)
- /frontend – Vite + Vue chat UI
- /docs – Private home documents (not committed)

## Development
Backend:
- `cd backend`
- `wrangler publish`

Frontend:
- `cd frontend`
- `npm install`
- `npm run dev`
